V.R World Media — Posting Dashboard

V.R World Media is a small media company operating four faceless short-form video brands: Heist (@Heisthq365official), Odds Board (@OddsBoardofficial), Faceless Wicks / Quiet Position (@facelesswicksofficial), and MH Outlanders (HuntersVaultOfficial).

The V.R World Media posting dashboard is an internal, single-operator tool that runs locally on the founder's own computer. It lets the founder compose a video post, save it as a draft, review and approve it, and then publish it to one of the YouTube channels he owns, using the YouTube Data API v3. Every upload is manually composed, reviewed, and approved by the channel owner in the dashboard before publishing — nothing auto-publishes.

The dashboard is not offered to the public, and no third-party accounts can be connected to it.
